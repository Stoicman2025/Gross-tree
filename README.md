# Семейное дерево

Сайт для всей семьи: интерактивное дерево с фотографиями, анкеты для родственников и проверка изменений администратором. Работает на бесплатном Cloudflare: сайт и сервер в одном Worker, данные в базе D1, фото в хранилище Workers KV. Банковская карта не нужна.

**Что умеет:**
- дерево с фото на карточках, полосы поколений с подписями десятилетий, перемещение и масштаб мышью или пальцами, поиск;
- два вида: «Вся семья» и «Предки и потомки» выбранного человека;
- профиль: ФИО с отчеством и девичьей фамилией, даты (можно примерные), места, род занятий, биография, галерея фото;
- несколько браков, разводы, приёмные дети, дети от разных браков;
- родственники заполняют анкеты, предлагают правки и присылают фото — всё приходит администратору на проверку;
- администратор видит, что именно меняется (было → станет), может поправить заявку перед принятием и объединить «нового» человека с уже существующим;
- «Кем приходится»: двоюродные, троюродные, внучатые, свёкор, тёща, золовка, шурин, сваты и т.д.;
- отметка «Это я»: в каждом профиле видно, кем человек вам приходится;
- печать дерева на листе A4…A0 и сохранение в PDF;
- импорт и экспорт GEDCOM (MyHeritage, Geni, FamilySearch, Gramps, «Древо Жизни»), резервная копия в JSON;
- удобно на телефоне, ставится на экран как приложение — иконка «Семья» (меню ☰ → «Иконка на экран телефона»). Подпись под иконкой меняется в `public/manifest.webmanifest` (`short_name`) и в `public/index.html` (`apple-mobile-web-app-title`).

## Запуск на Cloudflare (≈ 15 минут)

У вас уже есть Worker `gross-tree`, подключённый к репозиторию `Stoicman2025/Gross-tree`, и база D1 `family-tree-db` — они используются как есть.

### Шаг 1. Создать хранилище для фото

1. Откройте https://dash.cloudflare.com → слева **Storage & Databases** → **Workers KV** (или просто **KV**).
2. **Create** (или **Create a namespace**) → название `family-tree-photos` → **Create**.
3. В списке появится хранилище и его **ID** — строка из 32 букв и цифр. Скопируйте её.
4. Откройте файл [`wrangler.jsonc`](wrangler.jsonc) в Блокноте и замените `ВСТАВЬТЕ_СЮДА_ID_ХРАНИЛИЩА_KV` на скопированный ID (кавычки оставьте). Сохраните.

### Шаг 2. Задать пароль администратора и семейный код

1. В панели Cloudflare: **Workers & Pages** → **gross-tree** → **Settings** → **Variables and Secrets** → **Add**.
2. **Type**: *Secret*, **Variable name**: `ADMIN_PASSWORD`, **Value**: ваш пароль администратора (длинный, не используйте его больше нигде) → **Deploy** (или **Save**).
3. Ещё раз **Add**: *Secret*, `FAMILY_CODE`, значение — семейный код для родственников.

- **Придумайте новый код и пароль.** Старые «Наша семья» и «admin2024» лежат в открытом репозитории.
- Регистр букв, лишние пробелы и «ё/е» в семейном коде не важны.
- Секреты хранятся у Cloudflare в зашифрованном виде и не попадают в код и репозиторий.
- **Внимание:** в настройках есть два похожих раздела. Нужен **Variables and Secrets** на самой вкладке Settings. Раздел **Build → Variables and secrets** — для сборки, сайт его не видит.
- Позже семейный код можно менять прямо на сайте: **Админ → Настройки**. Пароль админа меняется здесь же, в секрете `ADMIN_PASSWORD`.

### Шаг 3. Обновить файлы на GitHub

В репозитории `Stoicman2025/Gross-tree`:

1. Удалите старые файлы: `index.html`, `worker.js`, `family-tree.html` (если есть). Откройте файл → значок корзины → **Commit changes**.
2. **Add file** → **Upload files** и перетащите из папки проекта:
   - папки `public`, `src`, `tests`, `tools`;
   - файлы `wrangler.jsonc` (уже с ID из шага 1), `README.md`, `HANDOFF.md`, `.gitignore`.

   Папку `Sonnet work` **не загружайте**: в ней старые коды доступа.
3. **Commit changes**. Cloudflare сам опубликует новую версию за 1–2 минуты. Проверить можно в **Workers & Pages → gross-tree → Deployments**: последняя публикация должна быть успешной.

### Шаг 4. Первый вход

1. Откройте https://gross-tree.stoicment.workers.dev (из России — через VPN).
2. Введите семейный код. Браузер запомнит его на полгода.
3. Меню ☰ → **Вход для администратора** → пароль из шага 2.
4. Нажмите **Добавить человека** и внесите себя, затем через профиль — родителей, супруга, детей.
5. Разошлите родственникам ссылку и семейный код.

Таблицы в базе создаются автоматически при первом открытии. Старую таблицу `data` от прежней версии можно удалить: **Storage & Databases → D1 → family-tree-db → Console** → `DROP TABLE data;`. А можно и оставить, она не мешает.

### Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Сайт ещё не настроен. Сообщите администратору» | Сервер не видит секрет `FAMILY_CODE`: проверьте имя (заглавными, без пробелов) и раздел — Settings → Variables and Secrets, а не Build (шаг 2) |
| «Вход администратора ещё не настроен» | То же для секрета `ADMIN_PASSWORD` |
| Публикация в Deployments завершилась ошибкой про KV | Проверьте ID хранилища в `wrangler.jsonc` (шаг 1) |
| «Исчерпан дневной лимит хранилища» при загрузке фото | Бесплатный KV принимает около 500 фото в сутки. Попробуйте завтра |
| Сайт не открывается из России | Адреса `*.workers.dev` в России работают только через VPN |
| Открылся «Демо-режим» | Сайт открыт не с Cloudflare (например, локально) — это нормально для просмотра |

## Как этим пользоваться

**Родственники:** открывают ссылку, вводят код, смотрят дерево, нажимают **Добавить человека** или **Предложить правку** в профиле, прикладывают фото. Всё уходит вам на проверку.

**Вы (администратор):**
- число у кнопки «Админ» — сколько заявок ждут проверки;
- **Принять** — изменения сразу появляются в дереве; **Изменить и принять** — поправить анкету перед принятием; **Отклонить** — с необязательной причиной, присланные фото удаляются;
- если родственник вписал «нового» человека, который уже есть в дереве, в заявке появится подсказка «Похоже, такой человек уже есть» — выберите его, чтобы не было дублей;
- ваши собственные правки применяются сразу, без заявок;
- **Админ → Данные → Скачать резервную копию** — раз в месяц. Cloudflare сам хранит историю базы за 7 дней, но долгосрочная копия — ваша.

## Бесплатные лимиты Cloudflare

| Ресурс | Лимит | Хватит на |
|---|---|---|
| Запросы к сайту | 100 000 в сутки | сотни посещений в день |
| База D1 | 500 МБ, 5 млн чтений и 100 тыс. записей в сутки | десятки тысяч человек |
| Хранилище фото KV | 1 ГБ, 1000 записей в сутки | 4–5 тысяч фото (сайт сжимает их до ~200 КБ), до ~500 новых в день |

Проект не «засыпает», если его долго не открывать. Лимиты могут меняться, актуальные — на https://developers.cloudflare.com/workers/platform/limits/

## Безопасность

- Без семейного кода не открываются ни дерево, ни фотографии. После ввода кода браузер получает защищённую cookie на 180 дней. При смене кода все такие «пропуска» сбрасываются.
- Родственники не могут ничего изменить напрямую — только отправить заявку. Менять данные может только вход администратора (cookie на 30 дней).
- Подбор кода и пароля ограничен: после 30 неверных кодов или 10 неверных паролей с одного адреса — пауза на час.
- Запросы, меняющие данные, принимаются только со своего сайта. Загружаются только фото JPEG до 4 МБ.
- Серверный код и настройки не публикуются: наружу видна только папка `public`.
- Сайт закрыт от поисковиков.

## Структура проекта

```
public/               сайт (то, что видит браузер)
  index.html, css/app.css, _headers
  js/main.js          запуск и связка интерфейса
  js/backend.js       связь с сервером (и демо-режим без сервера)
  js/model.js         связи в дереве
  js/layout.js        раскладка дерева
  js/kinship.js       «кем приходится»
  js/gedcom.js        импорт/экспорт GEDCOM
  js/apply.js         применение заявок
  js/photos.js        сжатие фото
  js/ui/…             окна, формы, профиль, админка, печать
src/worker.js         сервер: API, вход, заявки, фото, таблицы базы
wrangler.jsonc        настройки Cloudflare (база, хранилище фото)
tests/                автотесты
tools/serve.ps1       локальный просмотр
```

## Локальный просмотр и тесты

Ничего устанавливать не нужно. В PowerShell в папке проекта:

```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

- http://localhost:8790/public/ — сайт в демо-режиме (код `демо`, пароль админа `demo`, вымышленная семья);
- http://localhost:8790/tests/test.html — раскладка дерева, родство, GEDCOM, формы;
- http://localhost:8790/tests/worker-test.html — сервер целиком: база как настоящий SQLite, все API, защита и связка с сайтом.
